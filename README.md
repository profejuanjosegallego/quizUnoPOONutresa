# QUIZ PRÁCTICO – DRAGON BALL Z

⚡ Programación Orientada a Objetos (POO)

🌎 Contexto: ¡El universo Dragon Ball Z necesita programadores!

La Corporación Cápsula está desarrollando un sistema para administrar la información de los personajes, las transformaciones y las batallas del universo Dragon Ball Z.

Bulma ha solicitado tu apoyo como desarrollador para construir la primera versión del sistema utilizando los principios de la Programación Orientada a Objetos (POO).

Tu misión será diseñar e implementar tres clases en Java, aplicando encapsulamiento, constructores y métodos de acceso.

🎯 Objetivo

Demostrar el dominio de los conceptos fundamentales de POO mediante la creación de clases, atributos privados, constructores, métodos getters y setters e instanciación de objetos.

🛠️ RETO 1. Diseña tus clases

Crea las siguientes tres clases:

- 🥋 GuerreroZ: representa a los guerreros del universo Dragon Ball Z.
- 🔥 TransformacZion: representa los diferentes estados y niveles de poder de los personajes.
- 💥 Batalla: representa los enfrentamientos entre guerreros.

📌 Requisitos obligatorios

Cada una de las tres clases debe cumplir con lo siguiente:

1. 🔒 Declarar 10 atributos privados utilizando diferentes tipos de datos según corresponda ("String", "int", "double", "boolean", etc.).
2. 🏗️ Implementar un constructor vacío, sin parámetros.
3. ⚙️ Implementar un constructor lleno, que reciba los 10 atributos como parámetros y los inicialice.
4. 🔍 Implementar los 10 métodos getters para consultar los atributos.
5. ✏️ Implementar los 10 métodos setters para modificar los atributos.
6. 📚 Aplicar correctamente las convenciones de nomenclatura de Java.

Importante: Los atributos deben tener sentido dentro del universo Dragon Ball Z y de la responsabilidad de cada clase.

🚀 RETO 2. ¡Invoca tus objetos!

En una clase principal llamada "Main", con su correspondiente método "main", realiza las siguientes actividades:

🟢 Parte A. Constructor vacío

Crea 3 objetos utilizando el constructor vacío:

- 🥋 Un objeto de "GuerreroZ".
- 🔥 Un objeto de "Transformacion".
- 💥 Un objeto de "Batalla".

Después de instanciarlos, utiliza los métodos setters para asignar valores a sus 10 atributos.

🔵 Parte B. Constructor lleno

Crea 3 objetos utilizando el constructor lleno:

- 🥋 Un segundo objeto de "GuerreroZ".
- 🔥 Un segundo objeto de "Transformacion".
- 💥 Un segundo objeto de "Batalla".

Los valores de sus 10 atributos deben enviarse directamente al constructor.

🟡 Parte C. Consulta de información

Utiliza los métodos getters para mostrar en consola la información de los 6 objetos creados.

La información debe presentarse de manera organizada, identificando claramente cada objeto y sus características.

📊 RETO 3. Verifica tu implementación

Antes de finalizar, comprueba que:

- [ ] Se crearon correctamente las 3 clases.
- [ ] Cada clase tiene exactamente 10 atributos privados.
- [ ] Cada clase tiene constructor vacío y constructor lleno.
- [ ] Todos los atributos tienen sus getters y setters.
- [ ] Se instanciaron 3 objetos con constructor vacío.
- [ ] Se instanciaron 3 objetos con constructor lleno.
- [ ] Se utilizaron los setters para inicializar los objetos creados con el constructor vacío.
- [ ] Se utilizaron los getters para consultar los 6 objetos.
- [ ] El proyecto compila y se ejecuta sin errores.

📦 Entregable

El estudiante deberá entregar un proyecto Java que contenga:

📁 "src/"

- 📄 "GuerreroZ.java"
- 📄 "Transformacion.java"
- 📄 "Batalla.java"
- 📄 "Main.java"

El proyecto debe estar organizado, ser funcional y demostrar la correcta aplicación de los conceptos trabajados en clase.
